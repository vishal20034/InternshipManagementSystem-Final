# TEN Internship Portal — Coins & Daily Job Posting Plan (Prompt 2)

## Source: Client Instructions (June 2026) — Pending Full Implementation

---

## Overview

The **Daily Job Posting Task** is TEN's free marketing channel through interns.
Every intern shares TEN's hiring message on social media daily.
Coins system incentivizes compliance, reducing marketing cost to zero.

---

## Daily Job Posting Task — Coin Assignment by Domain

Students must post the TEN hiring drive message on:
LinkedIn, LinkedIn Groups, Facebook, Facebook Groups, WhatsApp, WhatsApp Groups, Telegram, Telegram Groups, Instagram, Instagram Communities

### Coin Values per Domain (10 coins/day cap)

| Domain | Base Coins/Day | Rationale |
|--------|---------------|-----------|
| HR Management | 12 | LinkedIn-heavy; max visibility |
| Web Development | 10 | Large social following expected |
| MERN Stack Development | 10 | Tech-savvy, active LinkedIn |
| Python Development | 10 | Strong dev community presence |
| Artificial Intelligence | 12 | High-engagement AI content |
| Data Science | 12 | Active community, viral potential |
| Software Engineering | 10 | Standard posting |
| Java Development | 8 | Smaller active social base |
| Flutter Development | 8 | Mobile dev community |
| Cyber Security | 10 | High LinkedIn engagement |
| DevOps with AWS | 10 | Cloud community active |

### Bonus Coins
- Submit tracking form link after posting: +3 coins
- Post on 5+ platforms in one day: +5 bonus coins
- 7-day consecutive streak: +20 coins
